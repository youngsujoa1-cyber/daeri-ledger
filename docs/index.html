대리장부 Daeri Ledger

대리운전·탁송 기사를 위한 진짜 순수익 장부 · 개발자 Topster

대리장부는 플랫폼 수수료와 건당 보험료를 정확히 빼서 손에 남는 돈을 보여주는 안드로이드 장부 앱입니다. 입력한 모든 기록은 오직 이용자의 기기에만 저장되며, 외부 서버로 전송되지 않습니다.

주요 기능

플랫폼별 정확한 수수료

카카오T·티맵·핸들·로지·콜마너·아이콘 등 플랫폼별 수수료율과 건당 보험료를 반영해 총매출 − 수수료 − 보험료 = 진짜 순수익을 계산합니다.

영업일 기준 장부

새벽 2시 콜도 전날 장부로 묶이는 영업일 기준(기본 낮 12시). 기준 시각은 직접 바꿀 수 있습니다.

3초 입력

플랫폼 칩 → 금액 칩 → 저장. 팁·경유비, 출발·도착, 특이사항은 같은 화면에서 바로 적습니다.

지출 · 미수금 · 휴무일

셔틀비·식대·월보험료 같은 지출, 미수금(후불) 콜의 입금 완료 처리, 일하지 않은 날의 휴무 표시까지 한 앱에서.

오늘 · 달력 · 콜밭 · 통계

하루 요약과 목표 진행바, 월간 달력, 내 주변 콜밭 거리순 정렬과 길찾기, 기간·플랫폼·요일·시간대별 통계.

백업 · 복원

CSV 내보내기, JSON 백업/복원, 대리 가계부 dcb_teras.zip 기록 가져오기까지 지원합니다.
